# entropy

Statistical tests of random number generators, and the generators, in safe
Rust.

`entropy` implements NIST SP 800-22 Rev. 1a, Marsaglia's DIEHARD and Brown's
DIEHARDER, with further tests after Knuth, Maurer, Marsaglia and Tsang,
L'Ecuyer and Simard, Doty-Humphrey, Webster and Tavares, and Ville, and runs
them over generators from the deliberately broken to the cryptographic.
Every test is written from its published description and the mathematics of
its null distribution; where the distribution has no closed form the crate
derives or simulates it, in a program under [examples](examples), and says
so.  Nothing is copied from another implementation, and every table is
derived here.

The same crate is a library of generators for programs: exact integer ranges
and Bernoulli trials, dense uniforms, ziggurat normal and exponential
variates, shuffles and weighted choices, a per-thread generator with fast
key erasure, and reproducible positioning and parallel streams.
[USAGE.md](USAGE.md) describes that interface.

Passing these tests is evidence of statistical quality, not proof of it, and
says nothing about unpredictability.

## Installation

The crate is `rng-entropy` on crates.io; the library is `entropy`.  It needs
Rust 1.87.

```sh
cargo add rng-entropy
```

Run the NIST battery on a generator:

```rust
use entropy::{nist, rng::Mt19937};

let mut rng = Mt19937::new(5489);
for result in nist::run_all(&mut rng, 1_000_000) {
    println!("{result}");
}
```

Draw values in a program:

```rust
use entropy::rng::{thread_rng, Sample};

let mut rng = thread_rng();
let die = rng.range(1, 7);
let z = rng.normal();
```

## Features

| Feature | Default | What it adds |
|---|---|---|
| `batteries` | yes | The `nist`, `diehard`, `dieharder` and `research` suites, and `rustfft` for the spectral test |
| `cryptography` | yes | The cipher-, hash- and DRBG-backed generators and `thread_rng`, from [`cryptography-rs`](https://crates.io/crates/cryptography-rs) |

With neither feature the crate is `entropy::{math, rng, result, seed}` — the
statistical generators, `Sample`, `Seedable`, `Advance`, `Streams`, the
probability functions and the result type — with no dependencies at all:

```sh
cargo add rng-entropy --no-default-features
```

The crate has no `unsafe` code and no foreign functions.  The tests use
[`rust-mp`](https://github.com/darrelllong/rump) to check the NIST fixture of
the digits of e; nothing else does.

## Running the batteries

```sh
tests/run_all.sh                     # everything, logged to logs/run_all-<host>-<date>.log
tests/run_battery.sh                 # NIST, DIEHARD and DIEHARDER
tests/run_battery.sh --suite nist --rng MT19937
tests/run_battery.sh --test nist::spectral --quick
tests/run_battery.sh --suite diehard-historical --rng PCG64
tests/run_aux.sh                     # the research probes
```

`run_tests`, the binary behind `run_battery.sh`, takes `--suite`, `--test`
and `--rng` patterns, `--quick` for shorter samples, `--json` for one object
per result, and `--corpus <file>` to test saved output (little-endian 32-bit
words) instead of a generator.  `--views` adds, for the 64-bit generators,
the low half, the full word and the bit-reversed high half beside the high
half the battery reads; `--alternatives` adds PCG64 with five specified
defects, so the report shows which tests detect each.  `run_all.sh` passes
both.

The research probes are their own binaries: `bib_tests` (Knuth's
permutation and gap tests, the Wald–Wolfowitz runs test, an ApEn profile),
`upstream_tests` (L'Ecuyer–Simard Hamming-weight tests, Doty-Humphrey's FPF),
`testu01_lz` (Lempel–Ziv compressibility), `webster_tavares` (avalanche),
`gorilla` (Marsaglia–Tsang), `sequential` (an anytime-valid martingale test)
and `bitplane_complexity` (Berlekamp–Massey per output bit).  Each takes
`--rng` and its own sizes; `cargo run --release --bin <name> -- --help`
lists them.

`scripts/run_r_report.sh` runs R's `randtests`, `tseries` and related
packages over every generator as an independent check; the report lands
under `target/`.

## Results

[TESTS.md](TESTS.md) is the full battery on every generator, regenerated by
`scripts/parse_battery.py` from a `run_all.sh` log.  [BENCHMARKS.md](BENCHMARKS.md)
is throughput on five machines, measured with
[pilot-bench](https://github.com/darrelllong/pilot-bench) through
`tests/run_benchmarks.sh`.

The battery is not one test.  On 200 000 null streams a Bonferroni decision
per family holds each family at its level, but with about sixty families
some family rejects 94% of null streams at 0.05, 42% at 0.01 and 5% at
0.001.  A verdict on a generator needs its own correction, or a reading of
which families failed and whether they share an input.  `stats/` keeps the
campaigns behind such statements: the null rates
(`battery-null-moore.txt`, read with `scripts/battery_null_report.py`), the
power of the NIST families against the five defects
(`nist-power-100-streams.txt`, `scripts/power_report.py`), the measured null
laws of the statistics the campaign found off their printed laws
(`statistic-scale.txt`, `statistic-validate.txt`), and the held-out
Lempel–Ziv cells.

Where a printed law was measurably wrong, the test scores by the measured
one and its documentation gives both: DIEHARD's count-the-1s difference
Q5 − Q4 has 1.0103 times the variance of the χ² that approximates it, and
Maurer's universal statistic has a standard deviation 6.5% above the
standard's σ at L = 5 and 1.1% below it at L = 10, and the spectral test's d
has standard deviation 1.026 at every sample size.  The parking-lot count's
law was confirmed over two million lots.

## Generators

The runner exercises, from the same `Rng` trait:

- **Operating system**: `OsRng` over `/dev/urandom`.
- **Degenerate controls**: `ConstantRng`, `CounterRng`.
- **Historical**: System V `rand()`, `mrand48()`, BSD `random()`, glibc
  `rand()`, FreeBSD `rand_r()`, Windows CRT `rand()`, VB6 `Rnd()`, .NET
  `Random`, the ANSI C, MINSTD and Borland LCGs.
- **Simulation**: MT19937, Xorshift32/64, PCG32/64, xoshiro256\*\*,
  xoroshiro128\*\*, SFC64, JSF64.
- **Cipher-based**: AES-128, Camellia, Twofish, Serpent, SM4, Grasshopper,
  CAST-128 and SEED in counter mode; Rabbit, Salsa20, SNOW 3G and ZUC
  keystreams.
- **DRBGs**: ChaCha20, `FastKeyErasureRng`, HMAC_DRBG and Hash_DRBG
  (SP 800-90A), AES-256 CTR_DRBG, the SHA3-512 and SHA-256 hash chains
  `SpongeBob` and `Squidward`, and Dual_EC_DRBG on P-256 as a backdoored
  control.

## What is implemented

| Tests | How they are checked |
|---|---|
| NIST SP 800-22: frequency, block frequency, runs, longest run, matrix rank, spectral, serial, approximate entropy, cumulative sums, universal, linear complexity, non-overlapping templates (all 148 aperiodic 9-bit templates), overlapping template, random excursions and its variant | The statistics of Rev. 1a; the unit tests run the publication's worked examples, including those on the first 10⁶ binary digits of e, and each module explains any printed figure that does not follow from the publication's own formulas |
| Maurer's universal test, L = 5 … 16 | Runs a setting when the sample holds the K ≥ 1000·2ᴸ blocks of §2.9.7; σ calibrated per L on 200 000 null streams |
| DIEHARD: birthday spacings, binary rank (31×31, 32×32, 6×8), bitstream, OPSO, OQSO, DNA, count-the-1s, parking lot, minimum distance, 3-D spheres, squeeze, runs, craps | Marsaglia's statistics with exact rank probabilities, squeeze's cells from an exact recurrence, disjoint letter fields and exact missing-word moments for the monkey tests, and Kolmogorov–Smirnov summaries over repeated trials |
| DIEHARD historical suite (opt-in): OPERM5, overlapping sums, count-the-1s and 6×8 rank on every byte offset | OPERM5's covariance built exactly by enumeration; the overlapping-sums correction computed from characteristic functions; each module documents its calibration |
| DIEHARDER: bit and byte distribution, DCT, fill tree, GCD, KS uniform, lagged sums, minimum distance in n dimensions, monobit², permutations | Brown's and Bauer's statistics; fill-tree's law exact, the GCD step law from a 10¹²-pair simulation; sparse χ² cells pooled so every observation is scored once |
| Knuth's permutation and gap tests; Wald–Wolfowitz runs; ApEn over m = 2 … 6 | `bib_tests` |
| L'Ecuyer–Simard Lempel–Ziv, Hamming-weight correlation and independence; Doty-Humphrey's FPF | `testu01_lz` and `upstream_tests`; the LZ78 phrase count against its exact law for k ≤ 5 and simulated laws above |
| Marsaglia–Tsang Gorilla; Webster–Tavares avalanche; Ville's martingale test of fair bits | `gorilla`, `webster_tavares`, `sequential` |

## Layout

- [src/nist](src/nist), [src/diehard](src/diehard), [src/dieharder](src/dieharder),
  [src/research](src/research): the tests, one module each, with the
  statistic, its null distribution and its author in the module documentation
- [src/rng](src/rng): the generators, `Sample`, `Seedable`, `Advance`,
  `Streams`, `thread_rng`
- [src/math.rs](src/math.rs): erfc, the incomplete gamma and beta, ln Γ,
  Student's t, Kolmogorov–Smirnov, Anderson–Darling and the FFT
- [src/main.rs](src/main.rs) and [src/bin](src/bin): the runner and the probes
- [examples](examples): the programs that derive the reference tables and
  measure the null laws
- [pubs](pubs): the standards and papers the code follows;
  `pubs/SOURCES.tsv` records where each came from, and [BIB.md](BIB.md) holds
  the BibTeX and marks what could not be kept (books, and papers whose
  publishers refuse download)
